# AI Toolbox

Набор бесплатных клиентских утилит для работы с текстом, файлами, изображениями и PDF.

Открывается на `/tools` — вкладка **Toolbox** рядом с вкладкой AI-инструментов.

## Главное свойство: всё считается в браузере

Ни один файл не уходит на сервер. Обработка идёт через Canvas API и `pdf-lib`
(подгружается динамически, только когда инструмент реально запускают). Поэтому
утилиты можно применять к чувствительным документам.

## Инструменты

**Текст**
- Счётчик символов, слов, строк и времени чтения
- Регистр текста (UPPER / lower / Заголовок / предложение)
- Удаление дублей строк и сортировка
- Очистка форматирования и лишних пробелов

**Данные**
- JSON: форматирование и минификация с проверкой синтаксиса
- Base64: кодирование и декодирование
- URL-энкодер / декодер
- Генератор slug для ссылок

**Изображения**
- Конвертация в PNG / JPEG / WebP
- Изменение размера с сохранением пропорций
- Сжатие с выбором качества

**PDF**
- Объединение нескольких PDF в один
- Разделение PDF по диапазону страниц
- Поворот страниц

## Технические детали

- Компоненты: `src/components/site/ToolboxView.tsx`, переключатель вкладок — `src/components/site/ToolsTabs.tsx`.
- `pdf-lib` импортируется динамически: `const { PDFDocument } = await import("pdf-lib")`.
- Результат отдаётся через `URL.createObjectURL` + программный `download`.
