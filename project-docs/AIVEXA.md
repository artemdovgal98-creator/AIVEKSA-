# AIVEXA — платформа поиска и сравнения AI-сервисов

Рабочее приложение (Next.js 15 App Router + TotalumSDK), а не макет: каталог, поиск,
подбор AI, избранное, статьи, реальный трекинг кликов и админ-панель.

## 1. Как стать администратором

Роль хранится в базе (`user.role`), никогда не берётся из cookie.

**Правило bootstrap:** пока в базе нет ни одного администратора, самый первый
зарегистрированный аккаунт (владелец сайта) автоматически повышается до `admin`
при первом же обращении к серверу. Как только админ появился — автоматическое
повышение больше не срабатывает никогда (`src/lib/admin-auth.ts`).

Порядок действий владельца:

1. Открыть `/register` и создать аккаунт **первым**.
2. Открыть `/profile` — там появится кнопка «Админ-панель», либо сразу зайти на `/admin`.

Обычный пользователь на `/admin` видит «Доступ запрещён», а все `/api/admin/*`
возвращают `403`.

## 2. Партнёрские ссылки (главная монетизация)

Ссылки **не зашиты в код**. У каждого сервиса в базе есть:

| Поле | Назначение |
|------|-----------|
| `official_url` | официальный сайт сервиса |
| `affiliate_url` | партнёрская ссылка (пусто по умолчанию) |
| `is_affiliate` | `yes` / `no` — включена ли партнёрская ссылка |

Логика выбора (`resolveTargetUrl` в `src/lib/localize.ts`):
`is_affiliate === "yes"` и `affiliate_url` не пустой → открывается партнёрская ссылка,
иначе — официальная.

**Как добавить партнёрскую ссылку:** `/admin/services` → карандаш у нужного AI →
поле «Партнёрская ссылка» → включить тумблер «Партнёрская ссылка активна» → «Сохранить».
Изменения применяются сразу, деплой не нужен.

При начальном заполнении базы партнёрские ссылки **не выдумывались**: у всех 41 сервиса
`is_affiliate = no`, `affiliate_url` пустой, кнопка ведёт на официальный сайт.

## 3. Трекинг кликов

Кнопка «🚀 Попробовать» ведёт не напрямую наружу, а на `/go/[slug]`
(`src/app/go/[slug]/route.ts`). Обработчик:

1. Находит сервис и вычисляет целевой URL.
2. Создаёт запись в таблице `clicks`: `service`, `clicked_at`, `device` (из User-Agent),
   `language`, `target_url`, `affiliate_click`, `user` (если пользователь авторизован),
   `country` — **только** если хостинг передал гео-заголовок (`cf-ipcountry`,
   `x-vercel-ip-country`, `x-country-code`); иначе поле остаётся пустым.
3. Делает 302-редирект на целевой URL.

Ошибка записи клика никогда не блокирует переход пользователя, но логируется.

Статистика в `/admin` считается **только по реальным записям**: клики за сегодня /
7 / 30 дней — фильтром по `clicked_at`, счётчики по сервисам — агрегацией
`clicks: { _count: true }` (без N+1). CTR показывается как `—`, пока нет ни одного
просмотра — фиктивные числа не подставляются.

Просмотры (`services.views`) увеличиваются при серверном рендере страницы `/ai/[slug]`.

## 4. Структура базы (Totalum)

| Таблица | Назначение |
|---------|-----------|
| `user`, `session`, `account`, `verification` | Better Auth (+ поля `role`, `language`) |
| `categories` | 12 категорий, названия `name_ru/uk/en`, `icon`, `order_position`, `active` |
| `services` | AI-сервисы: ссылки, тарифы, рейтинг, теги, тексты на 3 языках, флаги `featured/popular/active` |
| `clicks` | реальные переходы по кнопке «Попробовать» |
| `favorites` | избранное авторизованных пользователей (`user` → `service`) |
| `articles` | статьи AI Guide (`language`, `published`, `slug`) |
| `banners` | рекламные слоты (`position`, `active`) — по умолчанию выключены |
| `admin_settings` | настройки сайта (`site_name`, `ads_enabled=no`, `default_language=ru`) |

Наполнение: 12 категорий, 41 реальный AI-сервис, 8 статей (скрипты в `scripts/`).

## 6. Подбор AI (`/match`)

Реализован **без платных API**: задача токенизируется (стоп-слова RU/UK/EN), затем
ищется по названию, описаниям, тегам, ключевым словам и категориям; результаты
ранжируются функцией `scoreService` (`src/lib/catalog.ts`), score нормализуется в 35–100 %.

Точка расширения под LLM отмечена комментарием в `src/app/api/match/route.ts`: достаточно
обогатить строку задачи ключевыми словами через модель — остальной конвейер не меняется.

## 7. AIVEXA Tools

7 AI-инструментов (идеи, промпты, улучшение текста, названия, описания, посты, хэштеги)
работают через **встроенный в Totalum OpenAI** (`totalumSdk.openai.createChatCompletion`,
модель `gpt-4.1-mini`) — собственный ключ владельцу не нужен.
3 инструмента (счётчик слов, счётчик символов, форматирование) считаются в браузере мгновенно.

## 8. Мультиязычность

Языки: 🇷🇺 ru, 🇺🇦 uk, 🇬🇧 en. Выбор хранится в cookie `aivexa_lang`, поэтому его читают и
серверные компоненты (`src/lib/i18n/server.ts`), и клиентские (`src/lib/i18n/context.tsx`).
При смене языка вызывается `router.refresh()`, чтобы перерисовались серверные страницы,
а у авторизованного пользователя язык сохраняется в профиль.

Новый язык добавляется так: добавить код в `Lang`, объект в `LANGS`, словарь в
`dictionaries.ts` и (опционально) поля `*_xx` в таблицу `services`/`categories`.

## 9. Безопасность

- Все `/api/admin/*` защищены `requireAdmin()` — роль читается из базы.
- Запись полей идёт только через whitelist-билдеры (`src/lib/admin-payload.ts`) — mass assignment невозможен.
- TotalumSDK используется исключительно на сервере; секреты не попадают во фронтенд.
- `/admin`, `/api`, `/profile`, `/favorites`, `/go/` закрыты в `robots.txt`.

## 10. Реклама

Слоты `home_top`, `home_bottom`, `catalog`, `service_page`. Компонент `AdBanner` не
рендерит ничего, пока админ не создал активный баннер — на старте реклама выключена.

## 11. Готовность к Telegram (этап 2)

Отдельного каталога не создавалось: тот же бэкенд и те же API (`/api/services`,
`/api/categories`, `/api/match`) можно использовать из Telegram Mini App, а мобильный UI
(нижняя навигация, крупные кнопки, 360–430px) уже рассчитан на встраивание.
